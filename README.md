# sdd-hola-mundo
Aprender Spec Driven Development desde cero y practicar las bases con un proyecto simple.

## Prompt para empezar

Copiá y pegá esto en tu sesión de Claude Code para arrancar:

> Quiero hacer una página web que enseñe las bases de SDD con un hola mundo simple, ilustrada con OpenSpec. ¿Qué comando uso primero y para qué sirve? Guiame paso a paso. Usemos el proyecto sdd-hola-mundo.
