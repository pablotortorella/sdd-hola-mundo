# sdd-hola-mundo
Aprender Spec Driven Development desde cero y practicar las bases con un proyecto simple.

## Prompt para empezar

Copiá y pegá esto en tu sesión de Claude Code para arrancar:

> Quiero hacer una página web que diga Hola Mundo, usando SDD y luego quiero hacer otra que enseñe las bases de SDD, aterrizando todo con OpenSpec. ¿Qué comando uso primero y para qué sirve cada uno? Guiame paso a paso. Usemos este proyecto sdd-hola-mundo.
